# 论文修改文件

## 原始高清交付版

`original/` 保存首次交付的修改初稿和图件，不是用户最初上传的未修改原稿：

- `Manuscript_revised_draft.docx`：英文主稿，含中文批注及待核实实验条件。
- `Supporting_Information_revised_draft.docx`：支撑信息，41 张补充图分别编号和分页。
- `Figure_layouts_editable_v3.pptx`：可编辑图件布局与标签。实验谱线仍保留源位图，不是 Origin 数据项目。
- `Revision_notes_作者核实项.md`：修改说明、图号对应和核实清单。
- `Figure_sources/`：图件、独立面板及来源记录。

首次完整 ZIP 超过 GitHub 单文件 100 MB 限制，因此其内容在这里展开保存，未删减其中的文件。可在仓库主页选择 Code → Download ZIP 下载整个仓库。

## 使用前核实

这些文件是修改初稿，不是可直接投稿的定稿。实际 Al–Co–Fe–Ni–Mn 制备记录、PDMS 固化条件和原始作图数据仍需作者补充。博士论文 CoFeNiMnV 表征仅作文献参考，不能作为本工作实际样品的数据。没有应用不可访问的 Design Report 模板，也没有生成原生 Origin OPJU。
