## 重要限制

仪器已将Fe、Co区标为与其他金属Auger重叠。图中P1、P2等为数值模型组分，不代表唯一确定的Fe²⁺/Fe³⁺、Co²⁺/Co³⁺等价态。

C 1s主包络使用两个相近、未分辨的模型项，合并展示为P1+P2，不能当作两种分辨出的化学态。其余化学归属、面积比及原子百分比也未据此确定。保留仪器的284.8 eV碳参考轴，没有重复校正。

局部残差、边界受限参数和背景/模型不确定性仍需检查，不能仅凭高R²将此版作为最终投稿的价态分析。请参阅 [拟合说明](README_拟合说明.md)。正式价态分析需原始VGP/VGD以及匹配材料的多重态和Auger参考信息。
