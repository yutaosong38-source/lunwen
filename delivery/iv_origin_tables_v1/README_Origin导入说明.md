# I–V 曲线的图像估读与 Origin 数据

五条曲线：0、20、40、50、60 kPa。来源为原稿 Manuscript1.docx 图 2(b)，与本次截图同一张 I–V 图。这里没有仪器原始数值文件。

- IV_visible_points_DIGITIZED.csv：每条 9 个可见标记点的图像估读值，不是仪器原始数据。原点处曲线重叠，采用图中交点的 0 V/0 mA 估计。读图误差约 ±0.03–0.04 mA，不是实验测量误差。
- IV_0p2V_INTERPOLATED.csv：从 -2 至 +2 V，每 0.2 V 一个插值点，每条 21 点。分段线性插值，不是每 0.2 V 新测一次。
- IV_0p2V_SIMULATED_NOT_MEASURED.csv：在新增网格点加入独立的演示噪声（高斯 sigma=0.02 mA，限幅 ±0.04 mA，固定随机种子 20261013），已有公共网格锚点保持估读值。它仅供模拟散点和测试作图，不能作为实验结果、误差或重复性数据。
- IV_Origin_tables.xlsx：三类数据分别单列工作表；插值和模拟计算为可追溯公式，修改源电流估计后可更新。电压网格和区间映射固定。

## Origin

导入所需 CSV，A 列设为 X，B–F 列设为 Y。A 单位 V，B–F 单位 mA，对应 0、20、40、50、60 kPa。G 列为数据性质标签，不参与绘图。插值版适合恢复曲线趋势；模拟散点只能标为模拟/示意，不能标为实测。

单条曲线分别导出在 curves/ 文件夹，文件名和逐行标签区分插值或模拟。CSV 的多位小数来自计算，不意味着读图精度提高。
