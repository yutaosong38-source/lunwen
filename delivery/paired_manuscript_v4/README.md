## 仍需实验记录确认

两份是可继续逐段修改的成套审阅稿，不等于所有实验已独立验证的投稿终稿。正文有35处、SI有15处定位批注，主要事项为：

- 实际合金Al/Cu组分与mapping标签仍有矛盾，未靠更名或修图解决；文献XPS已明确更正为CoFeNiMnV/NCNTs参考体系，不作为当前样品价态证据。
- 图2的74.5 μV/K与SI厚度系列39–44 μV/K、不同压力曲线幅值，需要核对配方和归一化基准。
- RL的旧文−22 dB、比较图−28.7 dB及16 GHz EAB仍需同一样品、固定压缩后厚度的原始RL曲线；未将冲突数值写成已验证结论。
- SI原始刻度重复、部分纵轴字形和力学横轴缺标题已批注；没有猜测并重画实验轴。
- 制备细节、厂家、仪器、EMI条件、样本数及分类协议仍需真实记录。旧SI中按旧图选择的75:25配方没有冒充已实施的实际实验。
- 文献谱重用需确认引用及使用要求；比较表的文献数值需逐项核实。
