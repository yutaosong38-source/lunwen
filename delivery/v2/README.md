## 使用前说明

这是Origin风格的图件版式重建，不是原生 `.opju` 工程。SVG中的新增坐标文字、轴线和图4矩阵可编辑；实验曲线、峰拟合、显微照片及部分原图图例仍是源图像，未凭空重建原始数据。导出像素数增加不代表原始图像真实分辨率提高。

博士论文参考图S1–S15为CoFeNiMnV/NCNTs，与本文作者确认的Al–Co–Fe–Ni–Mn不同，不能作为本文样品的测试结果。来源图号已对应标注，正式发表前请核实再利用许可。

缺失方法参数及冲突数据仍需作者核实。阅读 [第二版说明](第二版说明.md) 和 [图件编辑说明](Origin_style_and_editing.md)，完成Word中的黄色缺项与批注后再用于正式投稿。
