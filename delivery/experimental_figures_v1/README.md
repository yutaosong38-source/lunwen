## 必须了解的限制

晶格间距按本次原图标尺与局部FFT估计，保守标注约0.19 nm和0.34 nm；未套用参考图数值或晶面编号。TEM(b)是(a)的真实裁剪放大，HRTEM(c)为另一张上传视野，不声称来自(a)/(b)同一颗粒。

Mapping只增强既有弱信号并统一显示颜色，五张源尺寸元素图处理前后非零信号位置完全一致。没有增添、移动、复制或随机化色点。标签放在数据区域外，不覆盖信号。

报告提供Fe、Co、Ni、Cu、Al，没有Mn。缺少空间校准，所以mapping没有擅加50 nm标尺；灰度图采集模式未确认，标为Electron image而不是擅称HAADF。Cu是否来自样品或铜网/载台仍待核实。

输出为300 dpi元数据的无损文件，但原始mapping有效区域约203×202像素；显示放大不能创造真实空间分辨率。正式投稿若需要更高清原始细节及标尺，须补仪器直接导出的文件。
