# XPS 第二版：暂定价态与逐峰含义

这是基于 A.xls 实测数据的探索性分峰及暂定解释，不是最终价态定量。问号表示尚未确证；有色经验项不等于一个独立价态。没有补造 Mn 曲线，也没有把 Mo 改标为 Mn。

## 方法与限制

Fe/Co/Ni 沿用 v1 的经验分解及仪器导出的 Smart 背景；原始点未平滑、未增加或删减。Fe/Co 的源表格明确包含其他金属 Auger 重叠。Cu 比较了仅双峰与双峰加宽损失项的模型；采用同宽、2p₃/₂:2p₁/₂ 全线形面积比 2:1，分裂间隔限于 19.5–20.1 eV 的候选模型。加宽项模型的 BIC 较低，但宽度达到 8 eV 上界，不能据此确认卫星及 Cu²⁺。Cu 净信号较弱，候选模型的 R² 约 0.40、约化加权残差约 1.52；它是未确证的线形候选，不是最终化学态分峰。

价态判断限制：Fe²⁺/Fe³⁺、Co²⁺/Co³⁺ 的多重态线形与 Auger 重叠尚未得到参考谱约束；Ni²⁺/Ni³⁺ 不能用额外自由峰简单区分；Cu⁰/Cu⁺ 需 Cu LMM（及 Auger 参数）等证据。能量轴保留原表格值，XPS.docx 提示其通常由最高 C1s 峰定标至 284.8 eV；碳材料须复核定标。Cu 的拟合中心约 933.88 eV 不能单凭峰位确证价态。不要将本图中的暂定标签写成论文中已证实的结论。

Mn：作者确认 Mo3d Scan 的表名误写，认为该页对应 Mn；此说法已记录，但该页横轴为 221.4–245.4 eV，与 Mn 2p（约 635–660 eV）不符，也不是 Mn 3s 的常用能区。目前不能把此页作为 Mn 高分辨谱用于价态分峰。需上传正确能区数据，或要求测试机构核实导出文件、能量轴和测量项目。没有据此判断样品不含 Mn。

## 图中符号

P1–Pn：经验模型项编号；FeOₓ / CoOₓ / NiOₓ：氧化相关包络，不指定唯一氧化物；Sat.：shake-up 等卫星峰候选；Loss：能量损失候选；Auger：俄歇信号重叠。2p₃/₂ 与 2p₁/₂ 是同一个 2p 能级的自旋轨道分裂，不是两种价态。

## 文件

XPS_metals_tentative_v2：总谱＋Fe/Co/Ni/Cu＋Mn 缺失提示；XPS_four_metals_v2：仅四种已有金属。PNG/TIFF 为 400 dpi，SVG/PDF 为矢量。逐峰说明有 Word 和 UTF-8 CSV；data 保留拟合曲线与全部原始扫描；diagnostics 用于查看背景、拟合和残差。

高清导出不提高实测能量分辨率。没有生成原生 Origin 项目；CSV 可以导入 Origin 重绘。没有报告价态百分比。
