# 时间响应数据与 Origin 2018b 脚本

包含起始灰色基线和 10、20、30、40、50、60、70 kPa 七个加载区间。横轴 Time (s)，纵轴 ΔR/R₀ (%)，向下为负值。灰色段原图未写压力，未擅自指定为 0 kPa。

## 数据表

Time_response_tables.xlsx 包含 Image_estimates（74 个图像估读点）和 Interpolated_0p2s（878 个分段插值点）两张表。A/B、C/D、E/F……O/P 是八组独立 XY 列对，按“基线、10～70 kPa”排序。每组不同长度，尾部空白代表没有点，不能补成零。

同名 XY CSV 用于整表导入，long CSV 记录逐行数据性质；segments/ 中提供每个区间的单独 CSV。表内电阻值以百分数数值存储，例如 -20 表示 -20%，不是 -0.20；不要再用 Excel 百分比格式乘 100。

估读方法：从原稿图 2(c) 的同一条彩色曲线定位峰顶、谷底；排除文字像素，保留各循环的不同幅值和间隔。图中峰顶接近零线，颜色交接处采用共用零线顶点估读，无法视为分别读出的独立测量。灰色基线微小振荡受图片分辨率限制较大。约 ±0.7 s 和 ±0.5～1 个百分点为读图误差量级，不是仪器误差。

0.2 s 表为分段线性插值，只在各已显示区间内加密，无随机噪声、无外推，不代表每 0.2 s 新做一次测量。严格等间隔网格可能错过尖锐谷底，默认脚本因此使用估读转折点直接连线，避免尖峰被网格采样削平。修改估读幅值可更新表内插值公式；更改转折时刻或采样间隔后需重建区间映射。

## Origin 2018b 运行

将全部文件解压到例如 C:\Origin_Time。打开 Origin 的 Window → Script Window，运行：

```text
run.section("C:\Origin_Time\TimeResponse_Origin2018b.ogs", Main);
```

Main 使用 74 个估读点。若要用 0.2 s 插值表绘图，将 Main 改成 Interpolated。

不想填写路径时，用记事本打开 Plot_Time_IMAGE_ESTIMATES.txt，复制全部命令至 Script Window，选中全部并按 Enter。插值版为 Plot_Time_INTERPOLATED_0p2s.txt。不要把 OGS 的段标题 [Main] 或 [Interpolated] 当普通命令粘贴。

脚本内置数据，不依赖 CSV 路径、Python、originpro 或新版本 API。使用连线图而非平滑曲线，保留原来的七种压力颜色和灰色基线。轴标题、刻度、压力标注与数据性质标识均设 Arial、28 pt。图中文字对象可在 Origin 中继续移动；不同内置模板或图页大小可能需要微调标注位置。

每次只新建工作簿和图，不删除或覆盖已有工程。Origin 内部 Greek / Subscript 文本格式用于 Δ 和下标 0。可在运行后保存为工程或导出 PNG/TIFF 600 dpi。
